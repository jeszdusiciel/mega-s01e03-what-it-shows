# Reproduce the desk view

Requires Node.js 24 or later. Run `npm ci` and `npm run build` from this folder.
The lockfile pins build dependencies. The build does not call production services.

The static renderer compiles the actual `.svx` pages through mdsvex and Svelte's server
renderer, with the supplied runbook layout and components. It expands the export's
Vite glob imports over the supplied files. Rendered pages are saved under `rendered/`.
Serve that directory with any static HTTP server to follow the KB's absolute links.
The explorer's current values and comparison cases render into HTML; live controls
need the original Svelte application to hydrate them. Tables, timeline and signature
are real component output, not manually recreated screenshots.

`evidence/assignments.json` and `tickets/*.md` are generated by the same build using the
supplied cause functions and tenant directory. All figures describe this export,
not production today. Five disputed reports remain associated with parser for count
reconciliation and are explicitly marked as requiring investigation.
